# Cloud-Computing

# 📌 Overview

This repository contains coursework and projects related to Cloud Computing, covering fundamental concepts, distributed computing frameworks, virtualization, data management, and cloud-based machine learning applications. The course provides hands-on experience in working with cloud platforms and building scalable distributed systems.

# 🏆 Key Topics Covered

- Cloud Infrastructure & Virtualization: Resource management, VMs, and containers
- Distributed Computing: MapReduce, Hadoop, Apache Spark
- Data Storage & Processing: Distributed file systems (HDFS, GFS), NoSQL databases
- High-Performance Computing in the Cloud
- Machine Learning in the Cloud: MLlib and cloud-based AI tools
- Resource Scheduling & Fault Tolerance: Managing large-scale cloud environments

# 📚 Technologies & Tools Used

- Cloud Platforms: Jetstream2
- Distributed Frameworks: Hadoop, Apache Spark
- Virtualization Tools: Docker, Kubernetes, Chameleon Cloud
- Programming Languages: Python, Java, SQL
- Machine Learning Libraries: MLlib, TensorFlow, PyTorch

# 💡 Project Highlights

- Cloud-Based Data Processing: Running large-scale jobs on distributed systems
- Virtualization & Resource Management: Performance comparisons of VMs vs. Containers
- Machine Learning on Cloud: Implementing ML models using cloud resources
- Data Storage & Retrieval: NoSQL database management & optimizations
